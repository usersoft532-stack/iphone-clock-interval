# 時計アプリをGitHub Pagesで公開する

このフォルダーの `index.html` をGitHubリポジトリのルートに置くと、GitHub Pagesで公開できます。

1. GitHubでリポジトリを作り、`index.html` をアップロードします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、ブランチを `main`、フォルダーを `/(root)` にして保存します。
4. 公開されたURLをiPhoneのSafariで開き、共有メニューから **ホーム画面に追加** を選びます。

GitHub Pagesのサイトはインターネット上に公開されます。計測記録はこのアプリを使うブラウザー内に保存され、GitHubには送信されません。
